# NTECH Board : règles du projet

## Langue du code : anglais (règle en vigueur depuis le 20 novembre 2026)

Tout **nouvel élément technique** est nommé en **anglais** :

- identifiants : variables, fonctions, types, composants, classes CSS, fichiers et dossiers ;
- API : routes, paramètres, champs JSON ;
- MCP : noms des outils et de leurs paramètres ;
- base de données : tables, colonnes, migrations ;
- variables d'environnement, clés de réglages, identifiants d'événements.

Ce qui existe déjà en français (par exemple les outils MCP `lire_ticket`, `modifier_ticket`, ou les
paramètres `etape`, `non_termines`) **reste tel quel** : on ne renomme pas l'existant, et le mélange des
deux langues est accepté. On ne crée plus de nouveau nom technique en français, même à côté de noms
français existants.

Les textes lus par les utilisateurs restent en français : interface, messages d'erreur affichés,
descriptions des outils MCP, e-mails, PDF.
